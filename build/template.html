차트 한글 표시 안내: 로컬 파이썬에서는 한글이 보이지만, Colab 에서는 글꼴 문제로 한글이 네모(□)로 깨질 수 있다

Colab 의 기본 글꼴(DejaVu Sans)에는 한글이 없다. 그래서 이 페이지의 예제는 차트 제목·축·범례를 영어로 적었다. 표(DataFrame) 출력과 print 의 한글은 Colab 에서도 깨지지 않는다.

Colab 차트에 꼭 한글을 써야 하면 아래 셀을 한 번 먼저 실행한다.

# Colab: 나눔고딕 설치 후 차트 글꼴로 지정
!apt-get -qq install fonts-nanum > /dev/null
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
fm.fontManager.addfont("/usr/share/fonts/truetype/nanum/NanumGothic.ttf")
plt.rcParams["font.family"] = "NanumGothic"
plt.rcParams["axes.unicode_minus"] = False   # 마이너스 기호 깨짐 방지

로컬 파이썬(내 PC 의 Jupyter, VS Code 등)은 PC 에 한글 글꼴이 깔려 있어 한글 차트를 그릴 수 있다. 단 matplotlib 기본값도 DejaVu Sans 이므로, 처음 한 번은 아래처럼 한글 글꼴을 지정해 둔다.

plt.rcParams["font.family"] = "Malgun Gothic"   # Windows (맥은 "AppleGothic")
plt.rcParams["axes.unicode_minus"] = False
