# 캐릭터 그림 넣는 곳

이 폴더에 아래 이름의 PNG(투명 배경, 정사각 512×512 권장)를 넣으면 말풍선 옆 동그라미에 자동으로 나타난다.
그림이 없으면 대체 그림 → 글자 배지(박·세·초·R) 순서로 보여 주므로, 하나도 없어도 페이지는 완성된 상태다.

| 캐릭터 | 먼저 넣을 1장 | 더 넣으면 쓰이는 그림 |
|---|---|---|
| 박사 | doc_smile.png | doc_explain.png |
| 세라 | asst_smile.png | asst_why.png |
| 초파리 | fly_point.png | fly_doubt.png |
| Money-Robo | robo_idle.png | robo_thinking.png, robo_wrong.png, robo_confused.png, robo_success.png |

얼굴이 위쪽에 오도록 그리면 된다(동그라미는 위 8% 기준으로 자른다).
